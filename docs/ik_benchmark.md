# Nero IK：Pinocchio FK 与解析 Jacobian 的离线对比

七轴 IK 保留 `NeroIK.forward(q)`、`solve(target_pose, q_seed)` 和 `last_diagnostics` 接口，目标仍是 `T_base_flange`，末端仍为 `link7`。替换逐关节 Python FK，并向原有 SciPy `least_squares` 提供解析 Jacobian；控制器无需改动。

位置残差仍为 `(p_actual - p_target) / 0.002`，旋转残差仍为 `log(R_target R_actual^T) / radians(2)`，正则项仍为 `0.05 * wrap_angle(q - seed)`。解析旋转导数为 `-Jlog3(R_target R_actual^T) @ J_angular`；Pinocchio 的线速度与角速度 Jacobian 都换算到 base 轴。正则项在原有角差分支内部的导数为 `0.05 I`。不将残差改成 SE(3) log，也不改变优化器的默认方法或停止条件。

URDF 限位、单 seed 求解、连续性验收、严格小于 2 mm / 2°的 FK 验收、80 次函数求值上限、75 ms 软预算和安全中间解回退均保留。新增 `jacobian_evaluations` 诊断字段；解析 Jacobian 调用也检查同一软预算。

## 对比方法

基线为提交 `b8aaeff4b54f1f9b5b3e8fc9d4ff682a74d4b2d0` 中的 `robot_control/nero_ik.py`，修改版为工作区实现。两版使用同一 URDF、目标和 seed，读取 `configs/quest3_nero_l20.yaml` 中的 `max_joint_delta_rad = 0.3345329252`（约 19.167°），而非类的默认 10°。

`data/episodes` 的 20 段轨迹共有 2,318 行。每段第一行没有上一帧反馈，跳过共 20 行，比较余下 2,298 个目标。目标取当前行的 `target_base_flange`，seed 取上一行的 `arm_joint_position`。录制数据没有保存发送前实际读取的 IK seed，因此这是统一 seed 下的对照，不能精确重建原始控制循环的求解过程。

每个目标交替先运行旧版或新版，预热前三个目标，各运行一遍。计时覆盖完整 `solve()` 调用，不包含数据读取与独立验收。所有返回解再使用旧版 FK 检查位置与旋转误差，并检查限位及连续性。0.5 秒以上的三处间断分别标记，另存连续段统计；相邻解变化不跨 episode 或长间断计算。

机器为 Intel Core i7-9700K；性能对比使用 `nero` 环境：Python 3.10.20、NumPy 1.26.4、SciPy 1.15.3、Pinocchio 4.1.0。耗时是本机这一次完整离线运行的结果。

平均求解快 **4.89 倍**。去掉三处长间断的 2,295 个目标后，两版仍均 100% 成功，平均耗时为 46.766 / 9.569 ms，结论一致。全部返回解均通过旧版 FK 的 2 mm / 2°验收和配置的 19.167°连续性检查。这是模型内误差验收，不代表实机标定精度。

同一目标的两版解，最大单关节差的中位数为 `3.21e-8°`，P95 为 **0.467°**，最大为 **13.584°**。旧版正常收敛的 2,065 个目标中，该差值最大仅 `6.74e-7°`；显著差异全部出现在旧版的 233 个超时回退目标中。新实现可以继续完成冗余自由度的优化，因此不能声称所有关节命令逐点保持一致。

最大差异发生在 `episode_20260929T091246.036723Z` 的第 98 行（从 0 开始计数）：最大单关节差为 13.584°，相对 seed 的七轴变化 L2 从旧版的 23.265°降至新版的 14.832°。对差异最大的八个目标额外进行离线诊断，仅将临时加载的旧版求解器预算放宽到 500 ms；旧版在约 91–167 ms 内正常收敛，与新解的差值均小于 `2.1e-7°`。这支持差异来自旧版提前终止的判断。生产实现及主对比的预算仍为 75 ms。

相邻变化统计覆盖 2,275 对输出。这些输出使用固定的录制反馈 seed，描述离线求解序列；不代表将新解发送给机器人之后的反馈轨迹。

## 复现与结果文件

在项目根目录执行：

```bash
/home/lab404/anaconda3/envs/nero/bin/python scripts/benchmark_nero_ik.py \
  --baseline-revision b8aaeff4b54f1f9b5b3e8fc9d4ff682a74d4b2d0
```

可用 `--episodes`、`--config`、`--output`、`--gap-seconds` 和 `--repeats` 指定路径、间断阈值与重复次数。脚本不构造硬件对象。

结果保存在 `data/benchmarks/nero_ik_pinocchio/`（随 `data/` 忽略，不提交录制数据）：

- `summary.json`：总体、连续段和间断目标的统计；环境版本、参数、源代码与每段轨迹 SHA-256。
- `samples.csv`：每个目标的耗时、成功状态、回退状态、关节解、相对 seed / 原记录命令的差值及旧版 FK 验收误差。
- `fallback_diagnosis.json`：差异最大的八个目标放宽旧版离线预算后的结果；该补充诊断与上面的主复现命令分开运行。
- `comparison.png` / `comparison.svg`：本次结果的静态图。

## 验证范围

`nerol20_wjy_py12` 环境（Pinocchio 2.7.0）下运行完整测试：**208 passed**。新增验证覆盖 50 组限位范围内随机姿态与旧 FK 的一致性、非零固定 world→base 变换、旋转残差从小角度到接近 180°的解析 Jacobian 与中心差分对照、真实小步求解、非法输入以及 Jacobian 超时后的原有回退行为。上述全量轨迹对比另外覆盖了 `nero` 环境的 Pinocchio 4.1.0。

没有连接机器人或修改录制数据。离线 IK 的改善不能单独证明控制循环已达到 20 Hz；实际频率仍需通过已有分阶段统计确认 retarget、发送及反馈读取的耗时。
