我们需要设计一个 agent 来完成一个十分简单的布料操作：双臂折叠抹布若干次。
第一版任一时刻只允许一个机械臂运动，另一臂保持位姿和抓持状态，暂时采用两臂依次动作的方式完成任务。
该 agent 使用 code as policy 风格执行对机械臂的操作，即在任务开始前将任务分成若干子任务，整个任务以 agent 规划并写代码 -> 代码执行，子任务完成 -> agent 根据当前 state 规划并写代码 -> ...的工作流进行，从而完成任务。每个子任务包括 planning, coding, execute。

该 agent 根据给定RGB观察图像、待操作物体上的关键点以及深度（因为我们使用的是RGB-D相机），自主地规划出若干 waypoint。我们希望 agent 能做成 ReKep 风格，包含 目标约束以及路径约束，但是使用 waypoint 来同时表达这两种约束，即在与物体接触时使用 waypoint 来表达抓姿等，在中间的运动过程使用 waypoint 来表达
agent 对于运动过程的偏好。同时 agent 可以选择使用 【对 waypoint 求 IK，然后在关节空间运动】 还是 【先在笛卡尔空间生成路径，再逐点求 IK】，从而调用不同的规划器。若规划器求解失败，则 agent 应当修改 waypoint，重新规划，保证交付。
waypoint 的规划位置以 L20 食指末端附近的点作为虚拟 TCP；agent 主要使用食指和拇指进行近似 gripper 的 top-down 抓取。具体开合手型、虚拟 TCP 的精确定义及法兰到 TCP 的标定参数待后续确定，参数暂时留空。规划时将 TCP 目标位姿换算为法兰目标位姿，再调用现有 IK。
该关节路径会在代码中被提前定义，并且在某一步通过执行器执行。执行器使用 TOPPRA 对关节路径进行时间参数化后下发执行。
此外，agent 能调用的运动函数包括：ptp（move_J）, 直线运动 (move_L)。
运动执行期间，agent 在所写程序中自行安排监督函数，持续检查任务状态。例如，程序异步启动运动、取得运动句柄后，在监督循环中读取观测并判断异常；底层执行器同时推进运动。监督函数发现异常时，由程序调用暂停保持工具，及时中断当前运动并保持设备姿势，反馈图像和当前 state，等待 agent 通过预定义交互方式提供新参数或命令，再进入已有恢复分支。运动正常完成时，以机械臂实际到位作为完成条件。

coding, execute 主要包括：
每个子任务由 agent 生成一份有完整主流程的普通 Python 程序，自行组织动作顺序、任务监控（code as monitor 风格）及异常恢复分支。程序可定义自己的辅助函数、监督循环或并发逻辑，不要求提供固定的 `policy(ctx, params)`、`monitor(state, history)` 入口。
我们预先提供运动、观测、几何计算、规划、暂停保持及 agent 通信工具，生成的程序通过导入工具库直接调用这些接口。运动工具支持异步启动并返回运动句柄，也支持等待运动完成；固定执行器负责实际发送运动目标和执行暂停保持，任务级的监督条件、调用时机及恢复流程由 agent 所写程序组织。
系统判断发生故障时，由程序负责暂停运动并保持设备当前姿势，程序继续存活，同时给出图像和当前 state 反馈，交给 MLLM 判断并通过预定义交互方式给出新的参数、命令，从而让代码在已有恢复分支中继续执行。等待 agent 回复期间，设备保持当前姿势。抓取或折叠是否成功由任务监控判断，与运动函数的到位完成区分。

为了防止系统复杂化，我们规定系统能力边界：整个系统通过 codex runtime 运行 agent，一个任务的完成就在一个对话 thread 当中，因此 agent 能够监督其所编写的程序执行；在代码执行过程中，即使发生异常，agent 也不允许通过停止程序、修改代码后重新执行来恢复，而是仅仅根据代码中定义好的交互方式修改参数并完成异常恢复，或者主动放弃任务，在任务结束后再总结经验（否则 agent 可能可以一直修改代码并尝试）。

当前软件入口为 `python3 -m cloth_agent.cli`，配置位于 `configs/cloth_agent.yaml`。生成的普通 Python 程序通过 `from cloth_agent.tools import ...` 导入工具，异步运动返回句柄，程序自行读取观测、暂停保持和请求 agent 回复，不要求固定的 policy/monitor 入口。完整调用说明与运行命令见 [README](../README.md#折布-agent-与普通-python-程序)。

本轮已接通假设备下的规划、监督、同进程参数恢复和真实 Codex thread 联调；演示验证两个软件阶段和一次注入异常，不代表实际布料操作成功。关键点、实际抓取手型和标定继续留待后续接入，实机暂停保持及折布尚待分级验证。
