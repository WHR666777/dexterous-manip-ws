## 任务

通过机械臂抓取来折叠抹布。

### 流程
- 读取机器人状态
- 获取并展示现场图像
- 收到图像反馈后，选择清晰可见且深度有效的布料边角抓取点
- 使用一次或多次布料移动过程，完成布料对折两次，即对折再对折，沿一条边对折一次，再沿之后的长边再对折一次。
  注意：布料在折叠后会有多层，需要一次抓住所有层 / 或者反复操作将所有层都折对。

### 一次布料移动过程的例子
- 以 L20 食指、拇指闭合接触点为 TCP，进行一次 top-down 抓取
- 沿 task +Z 抬升最多 0.10 m
- 获取并展示图像，判断是否抓住
- 判断一个合适的折叠放置点。验证后将布料放到折叠放置点、松手并撤离布面。

### 说明
你可以使用 Python 逻辑在一轮 tool call 里查询多个参数，执行多个行为，实现简单逻辑等。
写 Python 代码时避免 overly defensive 的行为 e.g. try-except。

折叠的水平运动过程可使用 move_L，并且与布料保持 0.10 m 左右的距离，防止移动过程中末端与桌面接触。
上下运动可使用 move_J。
遇到异常情况，重试，或者尝试恢复。
